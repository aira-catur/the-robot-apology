# The Robot Apology

Entry for the make.fun bounty [The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59).

[![Competition](https://make.fun/badge/u-suga-the-robot-apology-dd96bb59.svg)](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59)
[![Rank](https://make.fun/badge/u-suga-the-robot-apology-dd96bb59/aira-catur/the-robot-apology/rank.svg)](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59/leaderboard)
[![Reward](https://make.fun/badge/u-suga-the-robot-apology-dd96bb59/aira-catur/the-robot-apology/reward.svg)](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59)

A Python program (`main.py`, standard library only, deterministic, no network)
that writes a two-line robot apology to `entry.txt` in the output
directory (`MAKEFUN_OUTPUT_DIR` or `/output`): one sentence owning a
specific mistake, and one sentence naming the lesson and the fix that
follows from it.
